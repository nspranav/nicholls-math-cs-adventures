# Math & CS Adventures

Interactive browser games for the Nicholls State University SciTech Open House, Department of Mathematics.

## Games

- Bayou Rescue: algorithms and debugging.
- Cyber Detective: evidence-based cybersecurity decisions.
- Bayou Launch: quadratics and prediction.
- Coordinate Quest: ordered pairs, reflections, and translations.

## Play

Start at `index.html`, choose solo or pair play, then select a game. Each game includes hints and a Next family button that returns to the welcome screen.

## Hosting

This is a static HTML/CSS/JavaScript site. No build, backend, database, or API keys are required. In Settings → Pages, publish from `main` and `/(root)`.

## Local use

Open `index.html` in a browser, or serve this directory with a local static server. All game assets are included; Bayou Rescue also uses an optional Google Fonts stylesheet with local fallback fonts.
